Rollercoaster Height Checker (Python)

A beginner-friendly Python program that checks if a user is tall enough to ride a rollercoaster based on their height.

📌 Features

Accepts user height as input (in centimeters)

Checks eligibility to ride a rollercoaster

Displays a clear message based on the result

▶️ How It Works

The program welcomes the user.

It asks for the user’s height in centimeters.

If the height is 120 cm or above, the user is allowed to ride.

If the height is below 120 cm, the user is politely denied access
